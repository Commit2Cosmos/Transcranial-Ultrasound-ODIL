After: one objective, one config block

objective config (weights · scales · regulariser)

Problem. JointFreqODIL uses InverseLoss only as a bag of fields and computes its own objective. As a result, observation.normalize_data and loss.weights (default data: 100) are silently ignored in every real run.

Solution. Make one objective module own residuals, receiver sampling, scaling, weights and the term breakdown. The optimiser keeps only the parametrisation and the L-BFGS loop.

  • Locality: one definition of the minimised loss.
  • Config knobs match the code that actually runs.
  • Removes dead code: InverseLoss.evaluate, ForwardLoss, speed_offset.
  • Truth-vanishing and gradient tests cross one interface.
  • New test: the logged terms sum to L.
Live bug: the default YAML's loss.weights.data: 100 and normalize_data: per_receiver have no effect on the optimisation. validate_config also warns about loss.weights['reg'], which does nothing.

Problem. The optimiser reaches through the loss into the tape. The recorder then rebuilds metrics from the wrong source, so data_term is recorded with weight 100 instead of 1, and n_evaluations is always 0.

Solution. The optimiser emits a single iteration report to a single hook. The recorder owns all history and file output. LossTape stops serving as the callback.

  • Seam carries data, not object graphs.
  • Removes the hidden call-ordering constraint.
  • Fake sink tests the metrics columns.
  • Removes the parallel diag_rows record.
Depends on #1: the report's term breakdown comes from the deepened objective.

Problem. The inverse-crime baseline depends on the torch residual and the scipy solve being the same discrete operator. That knowledge is written out twice, by hand.

Solution. One operator module, built per band, owns the discretisation. The matrix-free and assembled forms become its two adapters, generated from one stencil table.

  • Two adapters make this a real seam.
  • Interface test: residual(solve(c), c) ≈ 0.
  • Removes dead BCs, the ABC and the 5 classes.
  • Kernel-matching tests become redundant.
Consistent with the Helmholtz-observation decision (D-005), and makes it safer. Once observations come from an independent forward model, the assembled adapter remains useful for the warm start.
