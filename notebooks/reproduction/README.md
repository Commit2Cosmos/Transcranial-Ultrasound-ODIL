# Information for `./notebooks/reproduction`

This subdirectory contains some work put together in an attempt to reproduce Figure 1 of the original ![ODIL paper](https://arxiv.org/pdf/2205.04611). The reference solution, ODIL, and PINN methodologies are replicated in full in `/components` and assembled in [reproduction.ipynb](./reproduction.ipynb). Other notebooks detail each approach more fully, but finalised implementations live in the `/components/*.py` files.
